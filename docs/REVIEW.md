# 模型链插件审查记录

审查日期：2026-10-24（Asia/Shanghai）。对象：WorkBuddy 辅助编写的 `dsh-model-chain`，由本地 0.1.0 修复为首个公开版本 0.1.1。

## 审查范围

逐一审阅 Host 接线、链适配器、持久化、浏览器设置和标签、bundle 声明，以及原有自测。实际接口对照本机安装的 DSH 0.2.1-rc.2 的 `dsh-llm`、`dsh-host-webserver` 和 `dsh-client-ui-model-selection` 实现。

## 已修复问题

| 问题 | 影响与修复 |
|---|---|
| 只处理错误 finish，没有处理抛出的异常 | 原版最小复现仅调用第一成员；现覆盖同步 dispatch 与迭代异常，未输出时降级，输出后终止 |
| 失败前透传 block-start、usage | 下一跳复用索引时可能形成错误内容块；现暂存前导元数据，失败时丢弃，成功时按顺序输出 |
| 无 finish 的结束被认为完成 | 可能吞掉截断或空结果；现返回 `CHAIN_STREAM_INCOMPLETE`，仅未输出时允许降级 |
| 禁用只隐藏目录 | 旧会话仍能直接调用；resolve 和 stream 均拒绝禁用链 |
| 初始化加载未被请求等待 | 重启初期可能看到空目录或被旧配置覆盖；现共用 readiness，并在加载完成后通知目录更新 |
| 保存共用 state.json.tmp | 并发重命名竞争、错误覆盖；现使用每路径串行队列、唯一临时文件及清理 |
| 所有读文件错误都被视为损坏 | 可能静默重置不可读配置；现仅对 JSON/结构错误备份后恢复，其他 I/O 错误上报 |
| 原始 API 无同源和本机边界 | 普通表单也能提交配置；现校验 loopback peer、Host、Origin、Content-Type 和请求体大小 |
| Buffer 分块直接拼字符串 | 分割在中文 UTF-8 字节中间时可能损坏；现合并 Buffer 后解码 |
| 保存时仍可编辑、标签切链时缓存未隔离 | 请求返回可能覆盖新输入，标签可能显示旧链成员；现保存时禁用编辑，观测记录按链隔离，菜单不轮询 |

## 自动验证

- `npm run check`：4 个运行源文件通过语法检查。
- `npm test`：原有 7 组核心自测、3 组标签自测，以及 14 项新增回归全部通过。
- HTTP 测试实际启动独立 loopback 服务并使用临时 `DSH_HOME`，验证并发保存、错误 JSON、Content-Type、Host/Origin 边界和大小限制；测试后清理其自有临时目录。
- `scripts/host-smoke.mjs`：在独立 Cordis Context 中加载真实 DSH 0.2.1-rc.2 的 LLM 服务和 BlockAssembler，验证第一成员抛错、第二成员成功及元数据隔离；使用假 provider，无真实模型网络调用。
- 发布打包使用 `package.json.files` 白名单，排除用户配置、凭据、依赖缓存和测试产物。

## 保留的限制

- 最近服务按整个 Host 的链聚合，会话并发共享，存在轮询延迟；不能据此做逐请求计费或归属审计。
- 不创建独立超时器，也不保证成员能力、上下文窗口或费用一致。
- 本地串行保存不等于跨进程锁；多个 Host 共用同一个状态文件仍是最后写入者覆盖。
- 设置 API 明确只支持本机访问；远程部署须另行接入宿主鉴权。
- 本次未发起真实付费模型调用，未重启用户的运行中 DSH。浏览器自测使用最小 React/slot 模型；未声称完成真实页面视觉验收或所有 DSH 版本的兼容测试。

上述限制已写入 README。发布前已知阻断问题已修复；本记录不构成不存在其他缺陷的保证。
